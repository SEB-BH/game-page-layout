## About

Websites need readable content, clear controls, and layouts that work at different widths. In this lesson, we will build a small game page to practice those skills. The same patterns are useful in booking forms, dashboards, online shops, and other websites.

We will change the page a little at a time. Each change will solve a problem we can see or test. Our page is a layout preview; adding the game logic with JavaScript is a separate task.
